🚀 FastAPI CRUD REST API with Validation

A **production-ready CRUD REST API** built using **FastAPI**, following clean architecture and modern backend best practices.  
This project demonstrates **field validation**, **path & query validation**, and a well-structured API design using **Pydantic** and **SQLAlchemy**.

---

📌 Overview

This repository is a practical FastAPI backend project that covers the core concepts required to build scalable REST APIs.  
It is suitable for:
- Backend beginners 👶
- Intermediate FastAPI developers 👨‍💻
- Interview & portfolio showcase 🎯

---

🛠 Tech Stack

⚡ **FastAPI**
🐍 **Python 3.10+**
📦 **Pydantic** – Request & response validation
🗄 **SQLAlchemy** – ORM
💾 **SQLite / PostgreSQL**
🌐 **Uvicorn** – ASGI server

---

✨ Key Features

✅ Full **CRUD operations** (Create, Read, Update, Delete)
✅ **Field validation** using Pydantic schemas
✅ **Path & query parameter validation**
✅ Clean and modular project structure
✅ RESTful API best practices
✅ Auto-generated API documentation (Swagger & ReDoc)
